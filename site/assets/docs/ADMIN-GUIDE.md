# AnjaniPutra Admin — How to use

Open the **AnjaniPutra Admin** icon on your phone, or type **yourwebsite/admin** in Chrome
(for example `anjaniputraproperties.in/admin`).

The first time, enter your PIN. Your phone will remember you.

---

## Add a new plot

1. Tap **＋ Add plot**.
2. **Photos**: tap **Add photos**, then take a photo or choose from the gallery. You can pick several at once.
3. Fill in the **Title** and **Location**. Both are required.
   - ❗ Do **not** write the project name in the title.
4. **Plot sizes & prices**: write the size in sq ft and the price, then choose **Lakh** or **Crore**.
   Tap **＋ Add another size** for more sizes.
5. Tick the **Amenities** and add **Nearby places**.
6. Write the project name and RERA number only in the 🔒 **Private** box at the bottom. It is never shown on the website.
7. Tap the yellow **Save** button. The website updates within about 5 minutes.

## Add a new flat

1. Tap **＋ Add flat**.
2. Add photos, then fill in **Title**, **Area**, **Flat type** (1, 2, 2.5 BHK…), **Floor**, **Carpet area** and **Price** (Lakh / Crore).
3. Tick the **Facilities** (Lift, Parking, Gym…).
4. Write the **Features** separated by commas, e.g. *East facing, Vastu compliant, Modular kitchen*.
5. Put the building name and owner contact only in the 🔒 **Private** box. Then tap **Save**.

## Change a plot or flat

Tap **Edit** → make changes → **Save**.

- To make a photo the first (main) photo, tap **★ Main** on it.
- To remove a photo, tap **✕**.

## Sold out, or hide for now

- **Few left** or **Sold out**: choose this under **Edit → Show on website**.
- **Hide**: the listing disappears from the website but stays saved. Tap **Show** to bring it back.

## Delete

Tap **Delete** → **Yes, delete**.
If you might want it again later, use **Hide** instead.

## Enquiries

Tap the **Enquiries** tab to see people who filled in the website form.

- 📞 **Call** or **WhatsApp** them with one tap.
- After talking to them, change the **Status**:
  New → Contacted → Visit booked → Visited → Booked (or Not interested).
- New enquiries are shown in orange.

## If something goes wrong

- **"Wrong PIN"**: check the PIN. After 5 wrong tries, wait 15 minutes.
- **"Something went wrong"**: check your internet connection and try again.
- Still stuck? Call your website helper.
